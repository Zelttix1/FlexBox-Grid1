Flexbox - Layout em uma dimensão

⬅ Voltar ao Hub

O que é Flexbox?

Flexbox é um modelo de layout CSS que organiza elementos em uma dimensão: em uma linha ou em uma coluna. Ele facilita o alinhamento, a distribuição de espaço e a adaptação dos itens ao tamanho disponível.

Para ativá-lo, coloque display: flex; no elemento pai. Esse elemento vira o container flex, e seus filhos diretos viram itens flex.

.container {
  display: flex;
}

1. Eixo principal e eixo transversal

flex-direction define o eixo principal. Com row, os itens ficam em linha; com column, ficam em coluna.

1
2
3
.container {
  display: flex;
  flex-direction: row; /* linha */
  /* flex-direction: column; para coluna */
}

2. Alinhamento e espaçamento

  • justify-content: distribui os itens no eixo principal.
  • align-items: alinha os itens no eixo transversal.
  • gap: cria espaço entre os itens.
HTML
CSS
JS
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}

Valores comuns de justify-content: flex-start, center, flex-end, space-between, space-around e space-evenly.

3. Quebra de linha e tamanho dos itens

flex-wrap: wrap; permite que os itens passem para outra linha quando não há espaço. A propriedade flex controla como um item cresce ou encolhe.

.container {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}
.item {
  flex: 1 1 130px;
}

Em flex: 1 1 130px, os itens podem crescer, podem encolher e começam com uma base de 130px.

4. Quando usar Flexbox?

  • Menus de navegação;
  • Alinhar ícone e texto;
  • Centralizar conteúdo;
  • Distribuir botões ou cartões em uma linha flexível.
.menu {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

Atividade prática

Crie um menu com três links. Use display: flex, experimente justify-content e depois habilite flex-wrap para observar o comportamento em telas menores.
