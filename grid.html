CSS Grid - Layout em duas dimensões

O que é CSS Grid?

CSS Grid é um sistema de layout que organiza elementos em duas dimensões ao mesmo tempo: linhas e colunas. É útil para criar estruturas de página, galerias e painéis de cartões.

O elemento pai vira um container grid quando recebe display: grid;. Seus filhos diretos passam a ocupar células da grade.

.container {
  display: grid;
}

1. Criando colunas

Use grid-template-columns para definir quantas colunas existem e qual é o tamanho delas. A unidade fr divide o espaço disponível em frações.

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

repeat(3, 1fr) cria três colunas com a mesma proporção.

2. Linhas, colunas e espaçamento

As linhas são organizadas automaticamente conforme os itens. A propriedade grid-template-rows permite definir alturas, enquanto gap controla o espaço entre as células.

.container {
  display: grid;
  grid-template-columns: 1fr 2fr;
  grid-template-rows: 80px 120px;
  gap: 12px;
}

Nesse exemplo, a segunda coluna ocupa o dobro da fração da primeira.

3. Controlando onde os itens aparecem

É possível fazer um item ocupar mais de uma coluna ou linha com grid-column e grid-row.

Cabeçalho (duas colunas)
Item 2
Item 3
Item 4
.cabecalho {
  grid-column: 1 / 3;
}

1 / 3 indica que o item começa na linha de grade 1 e termina na linha 3, ocupando duas colunas.

4. Layout responsivo

Com repeat(auto-fit, minmax(...)), a grade ajusta a quantidade de colunas ao espaço disponível, ajudando a criar páginas adaptáveis a celulares e computadores.

.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
  gap: 12px;
}

Quando usar Grid?

  • Layouts completos de páginas;
  • Galerias de imagens;
  • Painéis e dashboards;
  • Cartões distribuídos em linhas e colunas.

Flexbox costuma ser ideal para alinhar itens em uma dimensão. Grid é ótimo quando você precisa controlar linhas e colunas em conjunto. Os dois podem ser usados na mesma página.
